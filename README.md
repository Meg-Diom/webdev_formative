# WonderWorld – Discover the Beauty of Seychelles

## About the Project

WonderWorld is a tourism website designed to introduce visitors to the beautiful islands of Seychelles. The website showcases the country's breathtaking beaches, natural attractions, wildlife, culture, traditional cuisine and exciting activities.

The aim of this project is to provide visitors with an enjoyable way to discover Seychelles and inspire them to explore what the country has to offer.

## Website Pages

The website consists of five pages:

- **Home:** Introduces Seychelles, highlights its beauty, presents reasons to visit, and welcomes visitors to WonderWorld.
- **Explore:** Provides information about popular attractions, Seychellois culture and traditions, local cuisine, and activities visitors can enjoy.
- **About:** Introduces the developer, highlighting personal information, technical skills, soft skills and contact information.
- **Contact:** Provides contact details and a form for visitors to send enquiries or feedback.
- **Gallery:** Displays a collection of images showcasing the beaches, wildlife, culture and adventures of Seychelles.

## Features

- Navigation between all website pages.
- Informative descriptions of Seychelles and its attractions.
- Image gallery showcasing the beauty of Seychelles.
- Information about local culture, traditions and cuisine.
- Contact form with multiple input fields.
- External link to official tourism information.
- Consistent styling and visual theme throughout the website.

## Technologies Used

- **HTML5** – Used to structure webpages and their content.
- **CSS3** – Used to style the website, including layouts, colors, typography, images, hover effects and visual elements.
- **Visual Studio Code** – Used as the code editor.
- **Git and GitHub** – Used for version control and project hosting.

## How to Run the Website

1. Clone or download this repository.
2. Open the WonderWorld project folder.
3. Navigate to the `HTML` folder.
4. Open `index.html` in a web browser.
5. Use the navigation menu to explore the different pages.
